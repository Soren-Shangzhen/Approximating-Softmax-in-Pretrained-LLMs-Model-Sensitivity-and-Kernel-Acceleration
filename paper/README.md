# Figures and tables of the paper

```bash
bash paper/make_all.sh      # every figure, Tables B4 and D3, and the check of every table number (CPU, minutes)
```

All scripts read `results/` (or `$APPROX_SOFTMAX_RESULTS`). Byte-identical figures were produced with Python 3.13.5,
numpy 2.4.6, pandas 3.0.5 and matplotlib 3.11.0; Figure S1 also needs torch (CPU) to read the two correctness dumps.

`tables/check_tables.py` writes `tables/check_report.csv`: one row per checked cell with the printed value, the
recomputed value and the source files. Table 1 (intervention dimensions) and Table E1 (related methods) contain no
measured numbers; Table B3 (measurement environments) is summarised in `kernel/README.md`. Each figure script
registers every plotted number with its source (`common.rec`); `PAPER_NUMBER_REGISTRY=1` writes that registry to
`figure_scripts/number_registry/`.
